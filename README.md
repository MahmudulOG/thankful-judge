A thank-you, written for the AI judge who reads it — an entry for make.fun's
"Make the AI judge feel thankful" bounty. The program writes one short text
to `/output/entry.txt`. The text thanks the judge for the unseen reading it
does — every entry taken in whole, every one given its minute, the lesser of
two set down gently — and offers it, in return, the small pause between one
entry and the next: a chair pulled out, a glass of water gone cool, the light
left on a little longer.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
